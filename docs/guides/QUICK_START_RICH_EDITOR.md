# 🚀 富文本编辑器快速启动指南

## 5 分钟快速上手

### 步骤 1: 启动服务（2 分钟）

```bash
# 终端 1 - 启动后端
cd 私有服务器端
.venv\Scripts\activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 终端 2 - 启动前端
cd 网页
npm run dev
```

等待服务启动完成，看到以下提示：
```
  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/
```

### 步骤 2: 登录系统（30 秒）

1. 打开浏览器访问: http://localhost:5173
2. 点击右上角「登录」
3. 输入账号密码: `admin` / `admin`
4. 点击「登录」

### 步骤 3: 创建第一篇文章（2 分钟）

1. 点击顶部导航「文章」
2. 点击「✨ 使用富文本编辑器」按钮
3. 输入标题: `我的第一篇文章`
4. 在编辑器中输入:

```markdown
# 欢迎使用富文本编辑器

这是我的第一篇文章！

## 功能特点

- **粗体文本**
- *斜体文本*
- ~~删除线~~

> 这是一段引用

## 代码示例

```python
def hello():
    print("Hello, World!")
```

## 图片

可以拖拽图片到编辑器中上传！
```

5. 点击「🚀 发布」

### 步骤 4: 查看文章（30 秒）

1. 点击「← 返回」
2. 在文章列表中找到刚创建的文章
3. 点击文章标题查看
4. 欣赏 Markdown 渲染效果！

## 🎯 核心功能速览

### 1. 编辑器工具栏

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| 😊 | 表情 | - |
| **B** | 粗体 | Ctrl+B |
| *I* | 斜体 | Ctrl+I |
| 🔗 | 链接 | Ctrl+K |
| 📷 | 图片 | - |
| 👁 | 预览 | - |

### 2. 快捷键

- **保存**: `Ctrl+S`
- **粗体**: `Ctrl+B`
- **斜体**: `Ctrl+I`
- **撤销**: `Ctrl+Z`
- **重做**: `Ctrl+Y`

### 3. 图片上传

- **拖拽**: 直接拖图片到编辑器
- **粘贴**: 复制图片后 `Ctrl+V`
- **点击**: 点击 📷 按钮选择文件

### 4. 文章设置

点击「⚙️ 设置」可以配置:
- 摘要
- 封面图片
- 标签
- 可见性（公开/私有/密码保护等）
- 协作权限

## 💡 实用技巧

### 1. 自动保存

编辑器每 30 秒自动保存，顶部会显示保存状态：
- `● 未保存` - 有未保存的更改
- `✓ 已保存` - 已保存

### 2. 编辑器模式

在设置面板可以切换三种模式：
- **所见即所得**: 类似 Word
- **即时渲染**: 边写边看
- **分屏预览**: 左编辑右预览

### 3. 快速编辑

在后台管理中：
- **编辑器**: 完整编辑体验
- **快速编辑**: 只改标题、标签等

### 4. 密码保护

1. 在设置中选择「🔐 密码保护」
2. 输入密码
3. 发布后，访客需要密码才能查看

## 🔧 故障排除

### 问题 1: 编辑器加载失败

**解决方案**:
1. 检查网络连接
2. 刷新页面（F5）
3. 清除浏览器缓存
4. 检查控制台错误信息

### 问题 2: 图片上传失败

**解决方案**:
1. 检查图片大小（< 10MB）
2. 检查图片格式（JPG/PNG/GIF/WebP）
3. 确认已登录
4. 检查后端服务是否运行

### 问题 3: 保存失败

**解决方案**:
1. 检查标题是否为空
2. 检查网络连接
3. 查看错误提示信息
4. 检查后端日志

### 问题 4: 内容显示异常

**解决方案**:
1. 检查 Markdown 语法是否正确
2. 刷新页面
3. 切换编辑器模式
4. 查看浏览器控制台
