## 🐛 常见问题和解决方案

### 问题 1: 获取歌单失败 (409 Conflict)

**症状**：点击"我的歌单"提示"请先登录网易云"

**原因**：
- 没有登录网易云
- 或 cookie 已失效

**解决**：
1. 检查页面是否显示"已登录网易云"
2. 如果没有，点击"登录网易云"重新扫码
3. **确保在手机上点击了"确认登录"**
4. 等待显示"登录成功"

### 问题 2: 播放没有声音

**可能原因**：
1. 没有登录网易云 → 重新扫码登录
2. 歌曲版权限制 → 尝试其他歌曲
3. 浏览器音量关闭 → 检查音量
4. 浏览器自动播放限制 → 点击播放按钮（不要等自动播放）

**解决**：
1. 确认已登录网易云
2. 尝试播放不同的歌曲
3. 检查浏览器和系统音量
4. 查看浏览器控制台（F12）的错误信息

### 问题 3: 刷新后登录状态消失

**原因**：
- 浏览器 cookie 问题
- 或网易云 cookie 真的失效了

**解决**：
1. 使用无痕模式测试
2. 清除浏览器缓存
3. 重新扫码登录网易云

### 问题 4: Cookie 失效

**症状**：
- 之前能用，现在不行了
- 显示"已登录"但获取歌单失败

**原因**：
- 网易云 cookie 有时效性
- 可能在其他地方登出了

**解决**：
1. 点击"注销"按钮
2. 重新扫码登录
3. **确保在手机上点击确认**

## 📝 技术说明

### Cookie 存储机制

1. 用户扫码登录后，网易云返回 cookie
2. 后端使用 Fernet 加密 cookie
3. 加密后存储在 Redis：`cottage_listen:cookies:{user_uid}`
4. 默认 TTL：30 天

### Cookie 验证

- `has_cookie()` 现在会验证 cookie 能否解密
- 无效 cookie 自动清理
- 确保前端显示的状态准确

### 播放流程

```
1. 用户点击播放
2. 前端发送 WebSocket 事件
3. 后端更新 Redis 房间状态
4. 广播到所有连接的客户端
5. 前端获取歌曲播放链接
6. 调用 audio.play() 播放
```
