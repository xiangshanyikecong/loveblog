### 视觉特点

#### 1. 头像样式
- **形状**: 圆形 (border-radius: 50%)
- **尺寸**: 
  - 桌面端: 120px × 120px
  - 移动端: 90px × 90px
- **边框**: 4px 白色边框
- **阴影**: 
  - 主阴影: `0 8px 24px rgba(143, 155, 255, 0.25)`
  - 次阴影: `0 4px 12px rgba(255, 138, 181, 0.2)`
- **悬停效果**: 
  - 放大 1.05 倍
  - 阴影加深

#### 2. 占位符样式（无头像时）
- **背景**: 线性渐变 `linear-gradient(135deg, #8f9bff, #ff8ab5)`
- **文字**: 白色大写字母 (A 或 B)
- **字体大小**: 3rem (桌面) / 2.2rem (移动)
- **字重**: 800 (Extra Bold)

#### 3. 容器样式
- **背景**: 渐变 `linear-gradient(135deg, rgba(255, 182, 193, 0.15), rgba(173, 216, 230, 0.15))`
- **边框**: `1px solid rgba(255, 138, 181, 0.25)`
- **内边距**: 2rem
- **圆角**: 继承自 glass-card

#### 4. 心形图标
- **图标**: 💕 (双心)
- **大小**: 2.5rem (桌面) / 2rem (移动)
- **动画**: 心跳效果
  - 0%: scale(1)
  - 50%: scale(1.1)
  - 100%: scale(1)
  - 持续时间: 1.5s
  - 循环: 无限

#### 5. 标签文字
- **字体大小**: 0.9rem
- **字重**: 600 (Semi Bold)
- **颜色**: #64748b (灰蓝色)
- **对齐**: 居中

### 颜色方案

```css
/* 主色调 */
```

## 动画效果

### 1. 心跳动画
```css
@keyframes heartbeat {
  0%, 100% {
    transform: scale(1);
  }
  50% {
    transform: scale(1.1);
  }
}

.heart-icon {
  animation: heartbeat 1.5s ease-in-out infinite;
}
```

### 2. 头像悬停
```css
.couple-avatar:hover {
  transform: scale(1.05);
  box-shadow: 
    0 12px 32px rgba(143, 155, 255, 0.35),
    0 6px 16px rgba(255, 138, 181, 0.3);
}
```

### 3. 按钮悬停
```css
.btn-upload:hover:not(:disabled) {
  transform: translateY(-1px);
  box-shadow: 0 4px 12px rgba(143, 155, 255, 0.3);
}
```

## 性能优化

- 图片懒加载
- CSS 动画使用 `transform` 和 `opacity`（GPU 加速）
- 文件上传前进行客户端验证
- 图片自动压缩（后端处理）
- 缩略图生成（后端处理）
