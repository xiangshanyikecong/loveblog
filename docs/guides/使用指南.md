## 🎵 一起听功能使用指南

### 第一步：登录系统

1. 打开浏览器访问：**http://localhost:5173**
2. 使用测试账号登录：
   - 管理员：`admin` / `admin`
   - 伴侣账号：`partner` / `partner`

### 第二步：进入一起听

1. 登录后，点击导航栏的 **"小屋"** 或 **"Cottage"**
2. 在小屋页面中，点击 **"一起听"** 功能

### 第三步：登录网易云音乐

1. 在一起听页面，点击 **"扫码登录网易云"** 按钮
2. 页面会显示一个二维码
3. 打开 **网易云音乐手机 App**
4. 在 App 中扫描二维码
5. 在手机上确认登录
6. 登录成功后，页面会显示"已登录"状态

### 第四步：开始使用

登录成功后，你可以：

#### 🔍 搜索歌曲
- 在搜索框输入歌曲名、歌手名或专辑名
- 点击搜索结果中的歌曲

#### 📋 获取歌单
- 点击"我的歌单"按钮
- 选择你的网易云音乐歌单
- 浏览歌单中的歌曲

#### ▶️ 播放音乐
- 点击歌曲的"播放"按钮立即播放
- 或点击"添加到队列"稍后播放
- 使用播放控制按钮：播放/暂停、上一曲、下一曲

#### 🎶 实时同步
- 如果两个伴侣账号都登录了
- 一方的播放操作会实时同步到另一方
- 包括：播放/暂停、切歌、进度条拖动

## ⚠️ 常见问题解答

### Q1: 为什么每次打开都需要登录网易云？

**A**: 这是正常的，原因可能是：
- Redis 重启导致登录状态丢失
- Cookie 已过期（默认 30 天有效期）
- 后端配置改变导致加密密钥变化

**解决方案**：
- 重新扫码登录即可
- 如需长期保持登录，可以配置 Redis 持久化

### Q2: 获取歌单失败怎么办？

**可能原因**：
1. 网易云账号登录状态失效
2. Cookie 已过期
3. 网络连接问题

**解决步骤**：
1. 点击"登出"按钮
2. 重新扫码登录
3. 再次尝试获取歌单

### Q3: 歌曲无法播放？

**可能原因**：
1. 歌曲没有版权或需要 VIP
2. 播放链接已过期
3. 网络问题

**解决方法**：
- 尝试播放其他歌曲
- 检查网易云账号是否有 VIP 权限
- 刷新页面重试

### Q4: 双人同步不工作？

**检查清单**：
- ✅ 两个账号都已登录系统
- ✅ 两个账号都已登录网易云
- ✅ 都在"一起听"页面
- ✅ WebSocket 连接正常

## 🔧 技术说明

### Cookie 存储机制

- 登录后的 Cookie 使用 Fernet 加密存储在 Redis
- 存储格式：`cottage_listen:cookies:{user_uid}`
- 默认有效期：30 天
- 加密密钥从 JWT_SECRET_KEY 派生

### API 端点

```bash
# 获取二维码登录密钥
GET /v1/cottage/listen/auth/qr-key

# 检查二维码登录状态
GET /v1/cottage/listen/auth/qr-status?key={unikey}

# 登出
POST /v1/cottage/listen/auth/logout

# 获取房间状态
GET /v1/cottage/listen/state

# 搜索歌曲
GET /v1/cottage/listen/search?keyword={keyword}

# 获取歌单
GET /v1/cottage/listen/playlists

# 获取歌单歌曲
GET /v1/cottage/listen/playlists/{playlist_id}/tracks

# 获取歌曲播放地址
GET /v1/cottage/listen/songs/{song_id}/url
```

### WebSocket 连接

- 地址：`ws://localhost:8000/v1/cottage/listen/ws`
- 用于实时同步播放状态
- 支持的事件：播放、暂停、切歌、进度同步
