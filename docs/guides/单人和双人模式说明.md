# 一起听功能：单人和双人模式说明

## 🎵 单人模式

### ✅ 可以正常播放

**是的，单人打开时也可以正常播放！**

即使只有一个人在线，你也可以：
- ✅ 搜索歌曲
- ✅ 播放音乐
- ✅ 暂停/继续
- ✅ 切换上一曲/下一曲
- ✅ 拖动进度条
- ✅ 管理播放队列

### 工作原理

1. **房间状态存储在 Redis**
   - 当前播放的歌曲
   - 播放/暂停状态
   - 播放进度
   - 播放队列

2. **单人操作流程**
   ```
   用户操作 → WebSocket 发送事件 → 后端更新 Redis 
   → 广播事件 → 前端接收并更新 UI → 播放器播放
   ```

3. **即使只有一个人**
   - 所有操作都会保存到 Redis
   - 当另一个人上线时，会看到当前的播放状态
   - 实现"异步同步"

## 👫 双人模式

### ✅ 可以实时同步

**是的，双人在线时可以完美同步！**

### 同步功能

#### 1. 播放控制同步
- 一方点击"播放" → 另一方自动播放 ✅
- 一方点击"暂停" → 另一方自动暂停 ✅
- 一方切歌 → 另一方自动切换 ✅

#### 2. 进度同步
- 一方拖动进度条 → 另一方自动跳转到相同位置 ✅
- 播放进度实时同步（误差 < 2 秒）✅

#### 3. 队列同步
- 一方添加歌曲到队列 → 另一方看到更新 ✅
- 一方删除队列中的歌曲 → 另一方同步删除 ✅
- 一方清空队列 → 另一方队列也清空 ✅

#### 4. 登录状态同步
- 一方登录网易云 → 另一方看到"已登录"状态 ✅
- 一方登出 → 另一方看到"未登录"状态 ✅

### 同步原理

#### WebSocket 实时通信

```
用户 A 操作
    ↓
WebSocket 发送事件
    ↓
后端接收并处理
    ↓
更新 Redis 房间状态
    ↓
广播事件到所有连接
    ↓
用户 A 和用户 B 同时接收
    ↓
前端应用事件并更新 UI
```

#### 事件类型

1. **播放控制事件**
   - `PLAY` - 播放歌曲
   - `PAUSE` - 暂停
   - `SEEK` - 跳转进度
   - `NEXT` - 下一曲
   - `PREV` - 上一曲

2. **队列管理事件**
   - `QUEUE_APPEND` - 添加到队列
   - `QUEUE_REMOVE` - 从队列删除
   - `QUEUE_CLEAR` - 清空队列

3. **系统事件**
   - `LOGIN_OK` - 登录成功
   - `LOGOUT` - 登出
   - `COOKIE_EXPIRED` - Cookie 过期

#### 同步机制

1. **事件序列号（event_seq）**
   - 每个事件都有唯一的递增序列号
   - 前端使用序列号去重，避免重复处理
   - 确保事件按顺序应用

2. **时间戳同步**
   - 服务器时间戳 + 本地时间差
   - 计算播放进度的实时位置
   - 自动对齐（误差 > 2 秒时跳转）

3. **自动重连**
   - WebSocket 断线自动重连
   - 指数退避策略（1s, 2s, 4s, ..., 最多 30s）
   - 重连后自动同步最新状态

## 🔧 技术细节

### 房间状态（Redis）

```
cottage_listen:current (Hash)
├── song_id: "歌曲ID"
├── started_by: "用户UID"
├── started_at_ms: "开始时间戳"
├── position_ms: "播放位置（毫秒）"
├── paused: "0=播放中, 1=已暂停"
└── event_seq: "事件序列号"

cottage_listen:queue (List)
├── "歌曲ID1"
├── "歌曲ID2"
└── "歌曲ID3"

cottage_listen:event_seq (String)
└── "当前序列号"
```

### WebSocket 连接管理

```python
class ConnectionManager:
    # uid -> list of WebSocket
    _conns: dict[str, list[WebSocket]]
    
    async def broadcast(event):
        """广播到所有连接的客户端"""
        for uid, ws_list in _conns.items():
            for ws in ws_list:
                await ws.send_json(event)
```

   - WebSocket 会自动重连
